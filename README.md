# AVENOR Digital

Official website for AVENOR Digital — Technology That Moves Business Forward.

## Stack
- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Lucide icons

## Getting started
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Environment
Create a `.env.local` file and set the verified production website URL before launch:

```env
NEXT_PUBLIC_SITE_URL=https://your-verified-domain.com
```

Do not use an unverified domain in production. The canonical URL, sitemap and robots sitemap reference depend on this value.

## SEO foundation
- Page-level metadata defaults
- Open Graph and Twitter metadata
- Semantic page structure and descriptive links
- Generated robots.txt and sitemap.xml
- Configurable canonical metadata base

Service and location landing pages, structured data, analytics and Search Console verification will be added as the site content is finalised.
